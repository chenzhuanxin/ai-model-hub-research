01核心结论

国内的模型聚合层在 2025—2026 年完成了一轮明显分化：开源权重把 API 单价从「元/千 tokens」打到「元/百万 tokens」之后，平台的竞争点从「谁更便宜」转向「谁限流更松、模型更全、故障切换更稳」；同时大厂开放平台把免费额度从「永久」改成「90 天 / 首购一次性」，免费时代正在收口。

「一个密钥调多模型」已是及格线，差异在路由与限流

本轮核验的 20 个平台中，除智谱、MiniMax、百川、DeepSeek 等自研厂商外，其余平台均以「统一 OpenAI 兼容接口 + 模型广场」为基本形态：阿里云百炼、火山方舟、腾讯云 TokenHub 把自研与第三方模型收进同一网关，硅基流动、蓝耘元生代、天翼云星辰 TokenHub 则以聚合分发为主业。真正拉开差距的是限流与稳定性——百炼、方舟、TokenHub 与 MiniMax 公开了 RPM / TPM 口径（如 MiniMax 默认 500 RPM / 2000 万 TPM，千帆预置服务默认 5 QPS 并支持企业级提额），而多数中小平台只给「以控制台为准」。

免费额度从「永久」转向「限时 + 首购一次性」

20 个平台中 12 个提供免费额度或永久免费模型，但口径明显收紧：阿里云百炼的通义系免费额度由永久改为「开通后 90 天内有效」，火山方舟按「每个模型 50 万 tokens」在首次开通时一次性发放，天翼云星辰 TokenHub 的 50 万 tokens 只有 14 天有效期，无问芯穹更在 2026-03-30 直接取消了基础版 LLM API 免费服务。仍属「可持续免费」的主要是三类：腾讯云 TokenHub 的每模型 100 万 tokens（有效期 1 年）、讯飞星火个人 200 万 tokens 免费包、以及硅基流动与魔搭的多款永久免费模型 / 每日重置额度。

价格战停在「开源权重托管」这一层，旗舰自研模型仍是价格锚

第三方托管把开源权重的价格压到 DeepSeek-V3.2 输入 2 元/百万、GLM-5 输入 4 元/百万的量级；而自研旗舰的价格锚点反而在上移：GLM-5.3 输入 8 元 / 输出 28 元，qwen3.8-max 输入 12 元 / 输出 36 元，Doubao-Seed-Evolving 输入 6 元 / 输出 30 元。DeepSeek 在 2026-05 宣布 V4-Pro 永久降价至原价约 1/4 之后，又于 2026-08-17 引入峰谷计价、高峰时段输入 9 元 / 输出 27 元，说明「比原厂更便宜」这条路已经走到边界，平台要么靠路由与批量折扣挤出利润，要么向订阅套餐（Coding Plan / Token Plan）转移。

未纳入本图的条目及其原因见总表与待确认清单；订阅档高于 300 元/月的套餐（如腾讯云 TokenHub 企业版 500 元/月、智谱 Coding Plan 高阶档）超出坐标范围。

把门槛与评分放在一起可以看到两点：其一，国内聚合平台几乎没有固定月费门槛——14 个可定位的平台中 9 个记 0，只有智谱（Coding Plan 20 元/月起）、天翼云（Token Plan 29 元/月起）、MiniMax（Token Plan 49 元/月起）、阶跃星辰与讯飞星辰（套餐 99–200 元/月）把套餐做成独立商品；其二，门槛高低与质量基本无关，8.4–8.6 分的百炼、方舟、智谱分别落在 0 元与 20 元档，而门槛最高的讯飞（200 元/月套餐）评分与 0 元档的腾讯云 TokenHub 相近。免费额度的差异更能说明策略：可持续免费（每日重置、长期有效的免费模型、1 年有效的免费包）集中在腾讯云 TokenHub、硅基流动、魔搭、讯飞、智谱与 AI Ping；一次性或限时额度则是百炼（90 天）、火山方舟（首次开通）、天翼云（14 天）与商汤（活动已结束）的共同特征。换句话说，国内免费额度正在从「注册即得的永久池」变成「限时体验 + 订阅付费」。

05关键节点（2024—2026）

按公开可查的发布、降价、停服与策略变化时点排列，用于理解国内模型聚合格局是怎么形成的。

这条时间线的主线是价格与额度的双向收紧：2025 年下半年 MiniMax 用开源 M2 把旗舰价格锚点拉低，DeepSeek 则用峰谷计价与降价交替试探；2026 年第三方聚合（AI Ping、蓝耘、天翼云）与「Token 工厂」（商汤大装置、模力方舟）成为增量，而免费额度在无问芯穹、零一万物等平台上先后收缩或终止。对采购方的直接含义是：把「按量 + 可切换」作为默认架构，用聚合平台做比价与容灾，而不是把业务押在单一平台的免费额度上。
